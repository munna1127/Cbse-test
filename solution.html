Cayley-Hamilton Theorem Proof

Given Matrix
A = | 1 1 1 |
| 1 2 -3 |
| 2 -1 3 |
Step 1: Form Characteristic Matrix
A - λI = | 1-λ 1 1 |
| 1 2-λ -3 |
| 2 -1 3-λ |
Step 2: Find Determinant|A - λI| = 0

(1-λ)[(2-λ)(3-λ) - (-3)(-1)]
- 1[1(3-λ) - (-3)(2)]
+ 1[1(-1) - (2-λ)2]
Step 3: Solve DeterminantCharacteristic Equation becomes
λ³ - 6λ² + 5λ + 11 = 0
Step 4: Apply Cayley-Hamilton TheoremReplace λ with matrix A
A³ - 6A² + 5A + 11I = 0
Hence Proved that the matrix satisfies its characteristic equation.
